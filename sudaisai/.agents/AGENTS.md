# Workspace Agent Rules

## File Change Documentation Rule
- Whenever any file is **created**, **modified**, or **deleted**, you MUST update [PROJECT_DOCUMENTATION.md](file:///e:/project/sudaisai/PROJECT_DOCUMENTATION.md).
- Document:
  1. Date / timestamp of change
  2. File path (with file link)
  3. Nature of change (Created / Modified / Deleted)
  4. Why it exists, what it contains, its function/purpose, and how it works in the project.
